## Notes and rulings crossed
- Doc 17 treats cosmetic deviations from Unity as fine as long as gameplay is untouched; #6, #8, #10 (catchable) cross the economy line. The Fly ladder in SkinCatalog is tuned to ~50 Flys per run, so a bonus window shifts it; the user should decide.
- `Ids` tables in `SkinAssets.luau` / `SoundAssets.luau` are generated, so every new PNG or audio needs: file under Sprites/ (or audio dir), `build_manifest.py`, upload, `write_asset_ids.py`. Moderation delay is the schedule risk for new art with 15 days left (asset uploads were on 2026-09-19 in the past; "Reviewing" is fine, develop-API Green is the blocker).
- An id of 0 is a silent no-op, so a Halloween sprite that has not cleared moderation just falls back to the normal art. Safe to ship early.
- Never persist the window. All of these are derived from the date at runtime, so nothing touches `Profiles.luau` except #8.
- Do not move server-owned parts (World* scripts are cosmetic-only), so #10 cosmetic version must be a client-side fake.

## Recommended first 3 (15 days to Oct 31)
1. **#1 Spooky lava + #2 night/moon palette + #11 colour grade as one "Halloween mood" pass (S).** Config and tint only, no art, no moderation wait, no economy impact, and it dresses all four levels at once. Pairs with the costume's date window with a single helper.
2. **#3 Pumpkin / ghost / bat scenery (M).** The highest visual payoff per art file and fully client-only; the biggest asset pipeline lead time, so start the PNGs and uploads first (can overlap with step 1).
3. **#7 Halloween music + one stinger (M).** Audio changes the feel more than any tint and uses the same window helper; the Ludo skill can generate it. Risk is moderation time, so upload early.

Why not the others first: #6 and #8 are the most fun for players but need the user's economy ruling; hold them as a follow-up decision. #5 (candy flies) is a good fourth if art time remains.
